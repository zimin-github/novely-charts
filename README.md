# Novely Charts

Статический фид книжных подборок для приложения Novely.

Приложение не ходит в Open Library напрямую: этот хост принадлежит Internet
Archive и недоступен из ряда сетей, поэтому у части читателей «Открытия»
оставались пустыми. Здесь сбор данных выполняется на сервере GitHub — у него
доступ есть, — а телефон скачивает один статический файл, который отдаётся
через CDN GitHub Pages.

**Адрес фида:** `https://<логин>.github.io/novely-charts/charts/ru.json`

## Как это работает

1. `build_charts.py` собирает 7 полок: тянет чарты Open Library, а если источник
   не ответил или дал мало книг — дорезолвливает кураторский список через
   Google Books.
2. GitHub Actions запускает скрипт ежедневно в 04:00 UTC и коммитит результат.
3. GitHub Pages раздаёт `charts/ru.json` по HTTPS.
4. Приложение скачивает файл, кэширует его и показывает подборки. Если файл
   недоступен — работает встроенный резерв, экран пустым не будет.

## Настройка (один раз)

1. Создать публичный репозиторий `novely-charts` и запушить эту папку.
2. **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/`.
3. **Settings → Secrets and variables → Actions → New repository secret**:
   имя `GOOGLE_BOOKS_KEY`, значение — ключ Google Books.
4. **Actions → Update charts → Run workflow** — проверить первый прогон.
5. В приложении прописать адрес фида в `ChartFeedService.feedURL`.

## Что требует внимания потом

Полностью «настроил и забыл» не бывает, но обслуживания здесь минимум:

- **GitHub отключает cron в репозитории без активности 60 дней.** Так как бот
  коммитит файл при каждом изменении, активность есть. Если полки не менялись
  два месяца подряд — зайти и нажать Run workflow.
- **Если источник поменяет формат ответа**, скрипт не упадёт, а перейдёт на
  кураторский резерв: полки останутся, но перестанут обновляться. Признак —
  `"source": "curated"` во всех полках сразу.
- **Кураторские списки в `GENRES`** стоит освежать примерно раз в полгода,
  чтобы «Новые книги» не устаревали.

## Локальный запуск

```bash
GOOGLE_BOOKS_KEY=ваш_ключ python3 build_charts.py
```

На macOS со сборкой Python с python.org может понадобиться указать хранилище
сертификатов: `SSL_CERT_FILE=/etc/ssl/cert.pem`.

## Формат

```jsonc
{
  "schemaVersion": 1,
  "generatedAt": "2026-08-14T16:24:30Z",
  "shelves": {
    "popular": {
      "title": "Популярное",
      "source": "openlibrary",   // либо "curated"
      "books": [
        {
          "id": "…", "title": "…", "authors": ["…"],
          "publishedDate": "…", "description": "…", "isbn": "…",
          "coverURL": "https://…", "totalPages": 0
        }
      ]
    }
  }
}
```

Ключи полок совпадают с `DiscoverGenre.rawValue` в приложении. При изменении
структуры нужно поднять `schemaVersion` — приложение игнорирует фид с незнакомой
версией и показывает встроенный резерв.
